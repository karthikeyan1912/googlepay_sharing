# Google Pay Expense Sharing

A simple Python-based expense sharing application that helps friends manage shared expenses, calculate balances, and suggest payments.

## Features

- Add shared expenses
- Split expenses equally
- Calculate individual balances
- Display settlement status
- Suggest payments between friends

## Technologies Used

- PrettyTable
- NumPy

## How It Works

Users can:
1. Add an expense and select beneficiaries.
2. Automatically split the expense equally.
3. Calculate who owes or receives money.
4. Get suggested payments to settle expenses.
